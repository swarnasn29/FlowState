## 3. Pre-flight

Asks whether a live run will work *right now* — which is a different
question from whether the code is sound. It checks the chain's weight
rate limit, has the chain validate a real `SetWeights` without
submitting it, and confirms each published axon still points at this host
and has something listening.

The share column is the point: a 4-point accuracy difference becomes a
material difference in emissions, because weight is
`max(0, accuracy - 0.70) ** 2` rather than accuracy itself. A linear
curve would pay the better miner about 4% more and nobody would improve.

The organic lines are the product: a session with no known answer, relayed
to the miners, reports returned, deliberately **not** scored — there is no
ground truth to score against, and inventing one would reward agreement
with the validator rather than correctness.
